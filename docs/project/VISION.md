# Remembrall — Vision

## One-line

Expertise management platform: create reusable, shareable, interactive checklists. AI drafts the first one from a sentence.

## The problem

Procedures and instructions exist everywhere — in people's heads, in PDFs, in printouts that get lost. Nobody has built a platform that lets an individual expert publish their expertise publicly, under their own identity, in an interactive format anyone can run.

Internal SOP tools (Process Street, Trainual) serve teams. General tools (Notion, Docs) aren't purpose-built for procedures. Remembrall fills the gap between them: public-facing, branded, interactive, shareable expertise.

## The product

- **Account**: a chef, a town, a practitioner, a school — has a public-facing identity
- **Remembrall**: a structured, nestable, interactive checklist published under that account
- **Requirement**: a checklist item — text, checkbox, optional link to a nested Remembrall
- **AI generation**: type a task description → get an editable first draft

## The sharing loop

Every published Remembrall has a clean public URL. Recipients run it, save it, and register. Each share is a potential acquisition.

## Target markets (priority order)

1. **Content creators** — food, DIY, fitness, software — "write once, publish twice"
2. **Small professional experts** — coaches, therapists, consultants, agents, navigators
3. **Municipalities** — warm entry via Summit, NJ connection
4. **Healthcare/pharma** — general procedural and educational content (no PHI)
5. **Education** — warm entry via LessonWriter school relationships

## MVP goal

A user can create a private checklist, edit it, share a read-only link, and optionally generate a first draft from a plain-text description. Nothing else.
